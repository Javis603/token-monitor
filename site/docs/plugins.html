Using plugins

Add a readout or a custom view, then decide where it appears and what it can read.

Install, then allow

  1. Open Settings → Plugins → Official. System Monitor ships with the App; preview installable examples there.
  2. Review the exact source, version and requested permissions. Confirm installation.
  3. Allow and enable the plugin separately. Installation alone does not run its code. Extra permissions in an update pause execution until you approve them.

Use From file for a .tmplugin package. Author options under Installed → More plugin actions can import a folder. In Community → Manage sources, add an HTTPS catalog you trust; community entries remain Unreviewed.

Choose a placement

Open the plugin’s settings and enable its supported Home, tray, Edge Dock or Notch placements. Edge Dock/Notch also need their App switch enabled. A plugin appears in the main view menu only if it declares a page and you enable Main app page. A detached window is an optional action within that page.

Rich interfaces may offer another design for model/tool/device content. Choosing a design does not grant permissions. The host keeps an App default choice. Declared plugin preferences have a standard form that also works while the plugin is disabled.

Update, roll back or remove

Refresh a catalog to find versions and changelogs. Preview and confirm each update; it is not installed automatically. Rollback restores one saved compatible version, but does not undo plugin data migrations. Uninstall defaults to retaining data while removing placements.

Local files are unverified. SHA-256 checks bytes, not publisher identity or code safety. Optional key pinning is advanced; ordinary users do not need a public key.

Recover from a faulty plugin

Turn off that plugin, or use Enable plugins in Installed → More plugin actions to pause all plugins without losing individual selections. If startup is blocked, launch with --plugins-safe-mode or TOKEN_MONITOR_PLUGINS_SAFE_MODE=1. Repair the package before re-enabling it.

Plugin content follows App appearance. Skin presets remain supported; there is no separate My Style editor. See the management reference for storage and recovery details.

What approval and placement change

The permission list defines which app sources and capabilities plugin code may use. The source, version and requested grants deserve a new review on each install or access-expanding update. A placement only chooses where an already approved view appears; it does not expand its grants. A hidden view normally releases its visible sampling demand. Background checks require their own explicit enablement, and a cached Rich document does not keep collecting merely because it can reopen quickly.

Where personal plugin data goes

Managed packages, saved plugin data and placements are separate. Uninstall removes placements and normally keeps saved data so reinstall can recover preferences or notes. Rollback replaces one compatible code version; it does not reverse changes that code made to its data. Before sharing a package, test with a disposable profile and treat Community catalog text as the publisher’s claim. See distribution and recovery details.

使用插件

新增讀數或自訂檢視，然後決定它顯示在哪裡、可以讀取哪些資料。

先安裝，再允許執行

  1. 開啟設定 → 插件 → 官方。System Monitor 隨 App 提供，也可預覽可安裝範例。
  2. 核對來源、版本與權限，再確認安裝。
  3. 另外允許並啟用插件。安裝本身不會執行程式碼；更新要求更多權限時，會暫停執行直到重新核准。

使用「從檔案」安裝 .tmplugin。作者可在已安裝 → 更多插件操作匯入資料夾。在社群 → 管理來源加入信任的 HTTPS 目錄；社群項目仍標為未審核。

選擇顯示位置

在插件設定啟用支援的首頁、系統匣、Edge Dock 或 Notch 位置；後兩者也需要 App 本身的開關。只有宣告頁面並啟用「主程式頁面」的插件才會出現在主檢視選單，獨立視窗則是頁面內的選用操作。

Rich UI 可以提供模型／工具／裝置內容的另一種設計，但選擇設計不會授予權限，App 也保留「App 預設」。宣告的偏好設定有標準表單，停用插件時仍可修改。

更新、回復或移除

重新整理目錄以發現版本與變更記錄，每次更新都需要預覽並確認，不會自動安裝。回復可恢復一個相容的先前版本，但不能撤銷插件資料遷移。移除預設保留資料並移除顯示位置。

本地檔案未經驗證；SHA-256 只核對內容，不證明作者身分或程式安全。金鑰釘選是進階選項，一般使用者不需要公鑰。

處理異常插件

停用個別插件，或在已安裝 → 更多插件操作關閉「啟用插件」，暫停全部插件而保留個別選擇。若啟動受阻，可使用 --plugins-safe-mode 或 TOKEN_MONITOR_PLUGINS_SAFE_MODE=1。修復套件後再啟用。

插件預設跟隨 App 外觀，仍支援外觀預設，沒有獨立的 My Style 編輯器。儲存及復原細節請見管理參考文件。

授權與顯示位置的分別

權限清單決定插件程式能使用哪些 App 資料與能力。每次安裝或更新要求更多存取時，都應重新核對來源、版本及權限。位置只決定已批准的畫面在哪裡顯示，不會擴大權限。隱藏畫面通常會釋放可見取樣需求。背景檢查須另外明確啟用；Rich 文件即使可快速重開，也不會因此持續收集。

個人插件資料存放方式

受管理套件、插件資料與顯示位置彼此分開。解除安裝會移除位置，預設保留資料，重新安裝後可找回偏好或筆記。回復版本只替換一個相容的程式版本，不會逆轉程式對資料的變更。分享套件前請用可拋棄設定檔測試；社群目錄的文字是發佈者的聲稱。詳見發佈及復原說明。

使用插件

新增读数或自定义视图，然后决定它显示在哪里、可以读取哪些数据。

先安装，再允许执行

  1. 开启设置 → 插件 → 官方。System Monitor 随 App 提供，也可预览可安装示例。
  2. 核对来源、版本与权限，再确认安装。
  3. 另外允许并启用插件。安装本身不会执行代码；更新要求更多权限时，会暂停执行直到重新批准。

使用「从文件」安装 .tmplugin。作者可在已安装 → 更多插件操作导入文件夹。在社区 → 管理来源加入信任的 HTTPS 目录；社区项目仍标为未审核。

选择显示位置

在插件设置启用支持的首页、系统托盘、Edge Dock 或 Notch 位置；后两者也需要 App 本身的开关。只有声明页面并启用「主程序页面」的插件才会出现在主视图菜单，独立窗口则是页面内的选用操作。

Rich UI 可以提供模型／工具／设备内容的另一种设计，但选择设计不会授予权限，App 也保留「App 默认」。声明的偏好设置有标准表单，停用插件时仍可修改。

更新、回退或移除

刷新目录以发现版本与变更记录，每次更新都需要预览并确认，不会自动安装。回退可恢复一个兼容的先前版本，但不能撤销插件数据迁移。移除默认保留数据并移除显示位置。

本地文件未经验证；SHA-256 只核对内容，不证明作者身份或程序安全。密钥固定是高级选项，一般用户不需要公钥。

处理异常插件

停用个别插件，或在已安装 → 更多插件操作关闭「启用插件」，暂停全部插件而保留个别选择。若启动受阻，可使用 --plugins-safe-mode 或 TOKEN_MONITOR_PLUGINS_SAFE_MODE=1。修复包后再启用。

插件默认跟随 App 外观，仍支持外观预设，没有独立的 My Style 编辑器。存储及复原细节请见管理参考文件。

授权与显示位置的区别

权限列表决定插件代码能使用哪些 App 数据和能力。每次安装或更新请求更多访问时，都应重新核对来源、版本和权限。位置只决定已批准的视图在哪里显示，不会扩大授权。隐藏视图通常会释放可见采样需求。后台检查需要单独明确启用；Rich 文档即使可以快速重新打开，也不会因此持续采集。

个人插件数据存放方式

托管安装包、插件数据和显示位置分别保存。卸载会移除位置，默认保留数据，以便重装后恢复偏好或笔记。回滚只替换一个兼容的代码版本，不会逆转代码对数据的更改。分享安装包前请使用一次性配置测试；社区目录的描述属于发布者的声明。详见发布及恢复说明。

플러그인 사용하기

읽기 값이나 화면을 추가하고 표시 위치와 데이터 접근을 직접 선택하세요.

설치 후 실행 승인

  1. 설정 → 플러그인 → 공식에서 시작합니다. System Monitor는 앱에 포함됩니다.
  2. 정확한 소스, 버전과 권한을 확인하고 설치합니다.
  3. 별도로 승인하고 활성화합니다. 설치만으로 코드가 실행되지 않으며, 권한이 늘어나는 업데이트는 재승인까지 멈춥니다.

파일에서 .tmplugin을 설치하거나, 설치됨 → 추가 작업에서 폴더를 가져올 수 있습니다. 커뮤니티 → 소스 관리에서 신뢰하는 HTTPS 카탈로그를 추가해도 미검토 표시는 유지됩니다.

표시 위치 선택

플러그인 설정에서 지원하는 홈, 트레이, Edge Dock, Notch를 켭니다. Dock/Notch는 앱 설정에서도 켜야 합니다. 페이지를 선언한 플러그인은 메인 앱 페이지 배치를 켠 후 보기 메뉴에 나타나며, 별도 창은 그 페이지에서 엽니다.

모델/도구/기기의 Rich 디자인을 골라도 권한은 부여되지 않습니다. 앱 기본값으로 돌아갈 수 있습니다. 표준 설정 폼은 플러그인이 꺼져 있어도 사용할 수 있습니다.

업데이트, 롤백과 제거

카탈로그를 새로 고쳐 버전을 찾고 매번 확인 후 업데이트합니다. 자동 설치하지 않습니다. 호환되는 이전 한 버전으로 돌아갈 수 있지만 데이터 마이그레이션은 되돌리지 못합니다. 제거는 기본적으로 데이터를 남기고 배치를 지웁니다.

로컬 파일은 미검증입니다. SHA-256은 내용만 확인하며 작성자나 안전성을 증명하지 않습니다. 키 고정은 선택 가능한 고급 기능입니다.

문제가 생겼을 때

개별 플러그인을 끄거나 설치됨 → 추가 작업의 플러그인 활성화를 꺼서 선택을 유지한 채 전체를 멈춥니다. 시작이 막히면 --plugins-safe-mode 또는 TOKEN_MONITOR_PLUGINS_SAFE_MODE=1을 사용하고 복구 후 다시 켭니다.

모양은 앱을 따릅니다. 스킨은 지원하지만 별도 My Style 편집기는 없습니다. 자세한 내용은 관리 참조를 보세요.

승인과 표시 위치의 역할

권한 목록은 플러그인 코드가 사용할 앱 데이터와 기능을 정합니다. 설치나 접근 권한이 늘어나는 업데이트마다 출처, 버전, 요청 권한을 다시 확인하세요. 위치 설정은 이미 승인한 화면을 어디에 표시할지만 결정하며 권한을 넓히지 않습니다. 숨긴 화면은 보통 화면용 샘플링 수요를 해제합니다. 백그라운드 검사는 별도로 켜야 하며, 빠르게 다시 여는 Rich 문서가 그것만으로 계속 수집하지는 않습니다.

개인 플러그인 데이터

관리형 패키지, 저장 데이터, 표시 위치는 별개입니다. 제거하면 위치는 사라지지만 기본적으로 저장 데이터는 남아 재설치 후 설정이나 메모를 복구할 수 있습니다. 롤백은 호환되는 코드 버전 하나를 되돌리며 데이터 변경을 되돌리지는 않습니다. 공유 전 일회용 프로필로 검사하고 Community 카탈로그 설명은 게시자의 주장으로 읽으세요. 배포 및 복구 설명을 참고하세요.

プラグインの使い方

読み取り値や独自の画面を追加し、表示場所とアクセス権を選びます。

インストール後に実行を許可する

  1. 設定 → プラグイン → 公式を開きます。System Monitor は同梱されています。
  2. ソース、バージョン、要求権限を確認してインストールします。
  3. 別途許可して有効化します。インストールだけではコードは実行されません。更新で権限が増えると、再承認まで停止します。

「ファイルから」で .tmplugin を選べます。インストール済み → その他の操作でフォルダーを取り込めます。コミュニティ → ソース管理で信頼する HTTPS カタログを追加できますが、未レビューの表示は変わりません。

表示場所を選ぶ

プラグイン設定で対応するホーム、トレイ、Edge Dock、Notch を選びます。Dock／Notch はアプリ側でも有効化します。ページを宣言したプラグインだけが「メインアプリのページ」を有効にした後、表示メニューに現れます。別ウィンドウはそのページから開きます。

モデル／ツール／端末の Rich デザイン選択は権限を付与しません。「アプリの既定表示」に戻せます。標準の設定フォームはプラグインが無効でも使えます。

更新、ロールバック、削除

カタログを更新してバージョンを探し、毎回確認して更新します。自動インストールはしません。互換性のある直前のバージョンへ戻せますが、データ移行は元に戻りません。削除は既定でデータを残し、配置を解除します。

ローカルファイルは未検証です。SHA-256 はバイト列を確認するだけで、作者や安全性は保証しません。鍵の固定は上級者向けの任意機能です。

問題が起きたら

個別に無効化するか、インストール済み → その他の操作の「プラグインを有効化」をオフにして、選択を残したまま全体を停止します。起動できない場合は --plugins-safe-mode または TOKEN_MONITOR_PLUGINS_SAFE_MODE=1 を使います。

外観はアプリに従います。スキンは利用できますが、独立した My Style エディターはありません。詳細は管理リファレンスへ。

承認と表示場所の役割

権限一覧はプラグインコードが使えるアプリのデータと機能を定めます。インストールやアクセスが増える更新ごとに、配布元、バージョン、要求権限を再確認してください。配置は承認済みの表示先を決めるだけで、権限を広げません。隠した画面は通常、表示用のサンプリング要求を解放します。背景チェックは別途有効化が必要です。Rich 文書が素早く再表示できても、それだけで収集を続けません。

個人のプラグインデータ

管理パッケージ、保存データ、配置は別です。アンインストールは配置を消し、通常はデータを残すため、再インストール後に設定やメモを戻せます。ロールバックは互換コードの一版を戻しますが、コードが行ったデータ変更は巻き戻しません。共有前に使い捨てプロファイルで試し、Community カタログの説明は発行者の主張として扱ってください。配布と復旧の詳細を参照してください。

Usando plugins

Adicione um indicador ou uma visualização e escolha onde aparece e quais dados pode ler.

Instale e depois autorize

  1. Abra Configurações → Plugins → Oficial. System Monitor acompanha o app.
  2. Confira a fonte exata, versão e permissões antes de confirmar a instalação.
  3. Autorize e ative separadamente. Instalar não executa código. Novas permissões em uma atualização pausam a execução até aprovação.

Use De arquivo para .tmplugin, ou as ações adicionais em Instalados para importar uma pasta. Em Comunidade → Gerenciar fontes, adicione um catálogo HTTPS de confiança; os itens continuam Não revisados.

Escolha onde exibir

Nas configurações do plugin, ative Início, bandeja, Edge Dock ou Notch compatíveis. Dock/Notch também precisam do controle do app. Apenas plugins que declaram uma página aparecem no menu após ativar Página no app principal. Uma janela separada pode ser aberta pela página.

Selecionar um design Rich para modelos/ferramentas/dispositivos não concede permissões. A opção padrão do app continua disponível. O formulário padrão de preferências funciona mesmo com o plugin desativado.

Atualize, reverta ou remova

Atualize o catálogo para encontrar versões e notas. Confirme cada atualização; não há instalação automática. É possível restaurar uma versão anterior compatível, sem desfazer migrações de dados. A remoção mantém dados por padrão e remove os posicionamentos.

Arquivos locais não são verificados. SHA-256 confere bytes, não autoria ou segurança. Fixar uma chave é uma opção avançada, dispensável para uso comum.

Recupere um plugin com falha

Desative o plugin ou o controle Ativar plugins nas ações adicionais de Instalados para pausar todos sem perder escolhas individuais. Se a inicialização falhar, use --plugins-safe-mode ou TOKEN_MONITOR_PLUGINS_SAFE_MODE=1. Corrija antes de reativar.

A aparência segue o app. Presets de skin continuam disponíveis, mas não há editor My Style separado. Consulte a referência de gerenciamento.

O que aprovação e local de exibição mudam

A lista de permissões define quais dados e capacidades do app o código pode usar. Revise origem, versão e autorizações em cada instalação ou atualização que amplie o acesso. O local só determina onde uma visualização já aprovada aparece; não amplia permissões. Uma visualização oculta normalmente libera sua demanda de coleta visível. Verificações em segundo plano exigem ativação própria, e um documento Rich retido para reabertura rápida não continua coletando por isso.

Onde ficam seus dados de plugin

Pacotes gerenciados, dados salvos e locais de exibição são separados. Desinstalar remove os locais e normalmente preserva dados para recuperar preferências ou notas após reinstalar. Reverter restaura uma versão de código compatível, mas não desfaz alterações feitas aos dados. Teste em um perfil descartável antes de compartilhar; textos de catálogos Community são alegações do publicador. Veja distribuição e recuperação.
