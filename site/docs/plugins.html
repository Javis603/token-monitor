Token Monitor plugins

Install plugins, choose where their content appears, and manage updates or recovery. The plugin API is experimental and may change; plugins may need updates. Enable only code you trust.

Trust before enabling

Plugins can read local files and credentials, use the network, change data or freeze the interface. UI has no Node integration; a Node backend has the OS user’s authority. Enable only code you trust. A hash or signature is not a safety audit. Import a .tmplugin file or folder in Settings → Plugins. Review the revision and first-use settings, then choose Trust, install and enable to approve and run it, or Install only to keep it disabled and untrusted. Review initial locations, content sources, background execution and appearance together. Later enables and updates preserve your choices. The global switch and safe mode still apply. There are no bundled production plugins or automatic marketplace.

Choose content and locations

Place content on Home, pages, Notch, Edge Dock or Tray. Authors can also compose original native page content. Choose one replacement per target; additive views can coexist. App window shells remain native.

Updates and recovery

New executable content requires trust again; unchanged trusted code re-enables directly. Normal disable cleans up without a reload. Unsaved work prompts first; failed cleanup offers a recovery reload. Updating loaded code may reload affected renderers: save drafts first. Rollback restores code, not data migrations. Uninstall offers separate data and placement retention. Restart without plugins from the native tray menu, or use --plugins-safe-mode.

Token Monitor 外掛

安裝外掛、選擇內容顯示位置，以及管理更新與復原。外掛 API 屬實驗性，日後可能變更，外掛可能需要更新。只啟用你信任的程式碼。

信任後才啟用

外掛可能讀取本機檔案與憑證、連線、更改資料或令介面停止回應。UI 沒有 Node 整合；Node 後端具有作業系統使用者權限。只啟用你信任的程式碼；雜湊或簽章不代表安全審核。在「設定 → 外掛」匯入 .tmplugin 或資料夾，核對版本及首次設定，再選擇「信任、安裝並啟用」來執行，或「只安裝」以保持停用及未信任。首次設定一併確認顯示位置、內容來源、背景執行及外觀；重新啟用或更新會保留你的選擇。全域開關及安全模式仍然適用。平台沒有正式內建外掛或自動市集。

選擇內容及位置

可放在首頁、頁面、Notch、Edge Dock 或系統匣，也可組合原有頁面的原生內容。每個目標由使用者選一個替換者，附加內容可共存；視窗外殼仍由 App 管理。

更新與復原

新的程式內容須重新信任；已信任且未改變的程式可直接重新啟用。正常停用會清理外掛，不重載介面。有未儲存工作會先詢問，清理失敗則提供重載復原。更新已載入程式可能重載相關介面，請先儲存草稿。回退只恢復程式，不逆轉資料遷移；移除可分別保留資料及位置。原生系統匣選單可「不載入外掛並重新啟動」，亦可使用 --plugins-safe-mode。

Token Monitor 插件

安装插件、选择内容显示位置，以及管理更新与恢复。插件 API 为实验性，日后可能变更，插件可能需要更新。仅启用你信任的代码。

信任后再启用

插件可能读取本机文件和凭证、联网、修改数据或使界面停止响应。UI 没有 Node 集成；Node 后端具有操作系统用户权限。仅启用你信任的代码；哈希或签名不代表安全审核。在“设置 → 插件”导入 .tmplugin 或文件夹，核对版本及首次设置，再选择“信任、安装并启用”来运行，或“仅安装”以保持禁用和未信任。首次设置一并确认显示位置、内容来源、后台运行及外观；重新启用或更新会保留你的选择。全局开关及安全模式仍然适用。平台没有正式内置插件或自动市场。

选择内容和位置

支持首页、页面、Notch、Edge Dock、托盘以及原有页面内容组合。每个目标由用户选择一个替换者，附加内容可共存；窗口外壳由 App 管理。

更新与恢复

新代码需要重新信任；已信任且未改变的代码可直接重新启用。正常停用清理插件而不重载；未保存工作会先询问，清理失败则提供重载恢复。更新可能重载界面，请先保存草稿。回退不逆转数据迁移；卸载可分别保留数据和位置。通过原生托盘菜单不加载插件重启，或使用 --plugins-safe-mode。

Token Monitor 플러그인

플러그인을 설치하고 콘텐츠 표시 위치를 선택하며 업데이트와 복구를 관리하세요. 플러그인 API는 실험적이며 변경될 수 있어 플러그인 업데이트가 필요할 수 있습니다. 신뢰하는 코드만 활성화하세요.

신뢰 후 활성화

플러그인은 파일과 자격 증명에 접근하고 네트워크를 사용하며 데이터를 변경하거나 UI를 멈출 수 있습니다. UI에는 Node 통합이 없지만 Node 백엔드는 OS 사용자 권한을 가집니다. 신뢰하는 코드만 활성화하세요. 해시나 서명은 안전성 검토가 아닙니다. 설정 → 플러그인에서 .tmplugin 또는 폴더를 가져와 버전과 최초 설정을 확인하세요. 신뢰·설치·활성화를 선택하면 실행하고, 설치만 선택하면 비활성·미신뢰 상태로 보관합니다. 최초 설정에서 표시 위치, 콘텐츠 소스, 백그라운드 실행과 외관을 함께 확인합니다. 다시 활성화하거나 업데이트해도 선택을 유지합니다. 전체 스위치와 안전 모드는 계속 적용됩니다. 기본 제공 프로덕션 플러그인이나 자동 마켓은 없습니다.

콘텐츠와 위치

홈, 페이지, Notch, Edge Dock, 트레이와 기존 페이지 콘텐츠를 확장합니다. 대상별 교체는 사용자가 하나를 선택하며 추가 콘텐츠는 공존합니다. 창 외형은 앱이 관리합니다.

업데이트와 복구

새 코드는 다시 신뢰해야 합니다. 변경되지 않은 코드는 바로 다시 활성화됩니다. 정상 비활성화는 다시 로드하지 않고 정리합니다. 저장하지 않은 작업은 먼저 확인하며 정리 실패 시 복구용 다시 불러오기를 제공합니다. 업데이트 전에는 초안을 저장하세요. 롤백은 데이터 마이그레이션을 되돌리지 않습니다. 제거 시 데이터와 위치를 각각 보존할 수 있습니다. 기본 트레이 메뉴 또는 --plugins-safe-mode로 플러그인 없이 재시작합니다.

Token Monitor プラグイン

プラグインのインストール、表示位置の選択、更新と復旧を行います。プラグイン API は実験的で、今後変更される可能性があり、プラグインの更新が必要になる場合があります。信頼するコードだけを有効にしてください。

信頼してから有効化

プラグインはファイルや認証情報、ネットワークにアクセスし、データを変更したり UI を停止させる可能性があります。UI に Node 統合はありませんが、Node バックエンドは OS ユーザー権限で動作します。信頼するコードだけを有効にしてください。ハッシュや署名は安全性の審査ではありません。設定 → プラグインで .tmplugin またはフォルダーを取り込み、バージョンと初回設定を確認します。「信頼してインストール・有効化」で実行するか、「インストールのみ」で無効・未信頼のまま保存します。初回設定で表示位置、コンテンツの選択、バックグラウンド実行と外観をまとめて確認します。再有効化や更新でも選択を保持します。全体スイッチと安全モードは引き続き適用されます。標準の製品プラグインや自動マーケットはありません。

内容と表示位置

ホーム、ページ、Notch、Edge Dock、トレイと既存ページの内容を拡張できます。置換は対象ごとにユーザーが一つ選び、追加内容は共存できます。ウィンドウの外形は App が管理します。

更新と復旧

新しいコードには再び信頼が必要です。変更のないコードは直接再有効化できます。通常の無効化は再読み込みせず後処理します。未保存の作業は先に確認し、後処理の失敗時は復旧の再読み込みを案内します。更新前に下書きを保存してください。ロールバックはデータ移行を戻しません。削除時はデータと位置を別々に保持できます。ネイティブのトレイメニューか --plugins-safe-mode でプラグインなしで再起動します。

Plugins do Token Monitor

Instale plugins, escolha onde o conteúdo aparece e gerencie atualizações e recuperação. A API de plugins é experimental e pode mudar; os plugins podem precisar de atualizações. Ative apenas código em que você confia.

Confie antes de ativar

Plugins podem acessar arquivos, credenciais e rede, modificar dados ou travar a interface. A UI não tem integração com Node; o backend Node tem a autoridade do usuário do sistema. Ative apenas código confiável. Um hash ou assinatura não é uma auditoria de segurança. Importe um .tmplugin ou pasta em Configurações → Plugins e confira a versão e as configurações iniciais. Escolha confiar, instalar e ativar para executar, ou apenas instalar para manter desativado e não confiável. Revise os locais, fontes de conteúdo, execução em segundo plano e aparência juntos. Reativar ou atualizar preserva suas escolhas. O controle geral e o modo seguro continuam valendo. Não há plugins de produção incluídos nem mercado automático.

Conteúdo e locais

Use Home, páginas, Notch, Edge Dock, bandeja e composição de conteúdo nativo. O usuário escolhe uma substituição por destino; adições podem coexistir. O App controla a estrutura das janelas.

Atualizações e recuperação

Novo código exige confiança novamente; código já confiável e inalterado pode ser reativado diretamente. Desativar normalmente limpa o plugin sem recarregar. Trabalho não salvo exige confirmação; falhas de limpeza oferecem recarga para recuperação. Salve rascunhos antes de atualizar. Rollback não desfaz migrações de dados. A remoção pode preservar dados e locais separadamente. Reinicie sem plugins pelo menu nativo da bandeja ou --plugins-safe-mode.
