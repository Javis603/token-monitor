Trusted Desktop plugins

Build a same-page interface with an optional local Node backend. API 2 is experimental; API 1 is incompatible.

First manifest

Save this as manifest.json and add ui.mjs. Import the folder, enable the trusted revision, then choose Home.

Same-page interface

Author modules use DOM/CSS/JS inside the host renderer. There is no separate Rich document or fixed layout engine. Use bundled CSS and the actual native content/helpers where available. Node is not available in the UI.

Data and settings

Use ctx.data.query/subscribe for captured App usage, limits and sessions. A versioned settings schema provides a host form; a settings view can provide custom controls. Use an optional backend for files, network and computation; one process is shared across locations and stops when demand ends.

Test and distribute

Prebundle dependencies; installation never runs npm scripts. Test with synthetic data: idle, multiple surfaces, source changes, updates, native fallback and safe mode. Package with scripts/build-plugin-package.js. Native addons need target-platform and packaged verification.

Trust before enabling

Plugins can read local files and credentials, use the network, change data or freeze the interface. Enable only code you trust. A hash is not a security audit.

可信 Desktop 外掛

以同頁介面配合選用的本機 Node 後端。API 2 屬實驗性；不相容 API 1。

第一份宣告檔

儲存為 manifest.json 並新增 ui.mjs。匯入資料夾、信任啟用，再選擇首頁位置。

同頁介面

作者在宿主 renderer 以 DOM／CSS／JS 設計介面，沒有獨立 Rich 文件或固定排版引擎。可用套件 CSS、實際原生內容節點及可用的 helpers；UI 沒有 Node。

資料與設定

ctx.data.query／subscribe 提供 App 已取得的用量、額度及會話。版本化設定 schema 提供原生表單，settings view 可自製控制項。本機後端處理檔案、網路與計算，同一外掛跨位置共用一個程序，無需求便停止。

測試與發佈

依賴須預先打包，安裝不執行 npm scripts。用合成資料測試閒置、多位置、來源變更、更新、原生回復及安全模式。以 scripts/build-plugin-package.js 打包；原生 addon 需在目標平台及封裝版本驗證。

信任後才啟用

外掛可能讀取本機檔案與憑證、連線、更改資料或令介面停止回應。只啟用你信任的程式碼；雜湊不代表安全審核。

可信 Desktop 插件

同页界面配合可选本机 Node 后端。API 2 为实验性，不兼容 API 1。

首个声明文件

保存为 manifest.json 并创建 ui.mjs。导入文件夹、信任启用，再选择首页位置。

同页界面

作者通过宿主 DOM／CSS／JS 设计界面，没有独立 Rich 文档或固定布局引擎。可使用打包 CSS、原生内容节点和可用 helpers；UI 无 Node。

数据与设置

ctx.data.query／subscribe 提供已有用量、额度和会话。版本化 schema 提供原生设置表单，也可使用 settings view。本机后端处理文件、网络与计算；跨位置共享一个进程，无需求时停止。

测试与分发

依赖必须预打包，安装不运行 npm scripts。使用合成数据验证闲置、多位置、来源变化、更新、原生恢复和安全模式。通过 scripts/build-plugin-package.js 打包，原生 addon 需验证目标平台和打包版本。

信任后再启用

插件可能读取本机文件和凭证、联网、修改数据或使界面停止响应。仅启用信任的代码；哈希不代表安全审核。

신뢰 기반 Desktop 플러그인

같은 페이지의 UI와 선택적 로컬 Node 백엔드. 실험적 API 2는 API 1과 호환되지 않습니다.

첫 매니페스트

manifest.json으로 저장하고 ui.mjs를 추가하세요. 폴더 가져오기, 신뢰 및 활성화 후 홈 위치를 선택하세요.

같은 페이지 UI

호스트 DOM/CSS/JS로 디자인합니다. 별도 Rich 문서나 고정 레이아웃 엔진이 없습니다. 번들 CSS, 실제 네이티브 콘텐츠와 helpers를 사용할 수 있습니다. UI에는 Node가 없습니다.

데이터와 설정

ctx.data.query/subscribe로 기존 사용량, 한도와 세션을 읽습니다. 버전 있는 schema 또는 settings view를 사용하세요. 파일, 네트워크, 계산은 선택적 백엔드가 처리하며 위치 간 한 프로세스를 공유하고 수요가 없으면 중지합니다.

테스트와 배포

의존성을 미리 번들하세요. 설치는 npm scripts를 실행하지 않습니다. 합성 데이터로 유휴, 여러 위치, 소스 변경, 업데이트, 네이티브 복원 및 안전 모드를 검증하세요. scripts/build-plugin-package.js로 패키징하며 네이티브 addon은 대상 플랫폼 및 패키지 검증이 필요합니다.

신뢰 후 활성화

플러그인은 파일과 자격 증명, 네트워크에 접근하고 데이터를 변경하거나 UI를 멈출 수 있습니다. 신뢰하는 코드만 활성화하세요. 해시는 보안 검토가 아닙니다.

信頼する Desktop プラグイン

同一ページの UI と任意のローカル Node バックエンド。実験的 API 2 は API 1 と互換性がありません。

最初のマニフェスト

manifest.json として保存し ui.mjs を追加します。フォルダーを取り込み、信頼して有効化し、ホームを選びます。

同一ページの UI

ホスト DOM/CSS/JS で設計します。独立 Rich 文書や固定レイアウトエンジンはありません。バンドル CSS、実際のネイティブ内容と helpers を使用できます。UI に Node はありません。

データと設定

ctx.data.query/subscribe で既存の使用量、制限、セッションを取得します。バージョン付き schema または settings view を使用します。ファイル、ネットワーク、計算は任意バックエンドが担当し、位置間で一つのプロセスを共有、需要がなくなると停止します。

テストと配布

依存関係は事前にバンドルし、インストールは npm scripts を実行しません。合成データでアイドル、複数位置、ソース変更、更新、ネイティブ復旧と安全モードを確認します。scripts/build-plugin-package.js で梱包し、ネイティブ addon は対象環境とパッケージ版で検証してください。

信頼してから有効化

プラグインはファイルや認証情報、ネットワークにアクセスし、データを変更したり UI を停止させる可能性があります。信頼するコードだけを有効にしてください。ハッシュは安全性の審査ではありません。

Plugins Desktop confiáveis

UI na mesma página com backend Node local opcional. A API 2 experimental não é compatível com a API 1.

Primeiro manifesto

Salve como manifest.json e adicione ui.mjs. Importe a pasta, confie, ative e escolha Home.

UI na mesma página

Use DOM/CSS/JS do host. Não há documento Rich separado nem engine de layout fixo. CSS empacotado, conteúdo nativo real e helpers estão disponíveis. A UI não tem Node.

Dados e configurações

ctx.data.query/subscribe lê uso, cotas e sessões existentes. Use schema versionado ou settings view. Arquivos, rede e cálculos ficam no backend opcional, compartilhado entre locais e encerrado sem demanda.

Teste e distribua

Empacote dependências antes; a instalação não executa npm scripts. Teste dados sintéticos, inatividade, vários locais, mudanças de origem, atualizações, retorno nativo e modo seguro. Use scripts/build-plugin-package.js; addons nativos exigem verificação da plataforma e do app empacotado.

Confie antes de ativar

Plugins podem acessar arquivos, credenciais e rede, modificar dados ou travar a interface. Ative apenas código confiável. Um hash não é uma auditoria de segurança.
