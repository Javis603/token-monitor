# OmniRoute

OmniRoute is an open-source AI gateway that routes, compresses, and tracks LLM usage across multi-provider deployments.

## Identity and ids

`omniroute` is an AI Tool Limits provider. It connects to an OmniRoute gateway instance to track budget and quota pool consumption. Token usage generated by coding clients (such as Oh My Pi, Claude Code, or Codex) routed through OmniRoute is accounted for by their respective local client parsers.

## Data sources

- **Budget & Quotas**: Queried via `GET /api/usage/budget` (or `GET /api/quota/pools` when multiple pools are active).
- **Authentication**: Requires a Management Access Token (`oma_live_...`) minted from **Settings → Access Tokens** or an API key explicitly granted `manage` scope. Standard inference keys (`sk-...`) without management scope return `403 Invalid management token`.

## Credentials and transport

- `omnirouteToken` is persisted via the secure main-process credential store under `providers.omniroute.token`.
- `omnirouteBaseUrl` defaults to `http://localhost:20128` and accepts remote gateway endpoints (e.g., `https://omni.example.com`).
- Environment variable fallbacks: `TOKEN_MONITOR_OMNIROUTE_TOKEN`, `OMNIROUTE_TOKEN`, `OMNIROUTE_API_KEY`, `TOKEN_MONITOR_OMNIROUTE_BASE_URL`, and `OMNIROUTE_BASE_URL`.
