# Token Monitor 跨设备账号占用查看

## 功能定义

这是一个基于本地设备协作上报的“多设备、多 AI 服务商、多账号”管理视图。每台参与同步的设备上报自己正在运行的 AI agent、使用的服务商产品和规范化账号；现有 Hub 将这些任务状态与各设备采集到的该账号最新额度快照汇总，使主设备能够同时判断：

- Mac mini、Windows 主机、MacBook 等设备分别在运行什么任务；
- 同一个 GPT Pro、Claude、Gemini 或 Cursor 账号正在被几台设备使用；
- 任务是仍在运行、已正常结束、发生错误，还是设备失联后由 TTL 判定过期；
- 这个具体账号及其共享额度池还剩多少额度、数据来自哪台设备、更新时间是什么；
- 当前设备是否更适合手动选择同服务商的另一个账号，或切换到其他 AI。

例如：Mac mini 和 Windows 主机都在使用同一个 GPT Pro 账号时，MacBook 应在同一账号卡片下看到两个任务及其设备来源，并结合用户自定义占用阈值、最新额度和真实请求被动产生的限流/延迟证据给出建议。系统不能自动切换账号、停止任务、发送测速探针，也不能把建议阈值宣传成服务商公布的并发限制。

统一关系模型为：

`设备 → AI 产品/agent → 规范化供应商账号 → 当前/最近任务 → 额度池与被动健康证据`

当前补丁已经实现账号登记、跨设备短期任务记录、实时 Hub 汇总、设备/任务标签、最近完成/失败/停止/过期时间线，以及与 Token Monitor 现有逐账号额度快照的显式绑定。额度绑定不会按套餐名、供应商单例或 `chatgpt → codex` 隐式猜测；多账号时必须由用户确认。尚未完成的是基于真实请求的被动首响应延迟和 429 判断，因此额度灯与占用建议灯保持为两项独立证据。

## 先说明能力边界

在本机登录 ChatGPT、Claude、Gemini、Cursor 等账号，并不能直接查询同一账号在其他设备上正在生成几个任务。服务商通常没有面向个人账号提供这种实时设备占用接口。Token Monitor 采用参与式上报：每台设备观察自己启动的任务，把不含对话内容的短期占用记录发给同一个 Hub，再由 Hub 汇总。

因此，只有安装并连接到 Hub 的设备才可见。未安装、离线或未配置上报的设备不会被“远程发现”。心跳停止后，记录会在默认 45 秒 TTL 后自动过期。

## 推荐部署

1. 选择一台经常在线的电脑，在 Token Monitor 的“设置 → 多设备同步”中选择“在此设备托管 Hub”，或运行现有的 `npm run hub`。
2. 设置随机的 `TOKEN_MONITOR_SECRET`。跨网络时优先使用 Tailscale、ZeroTier 等可信 VPN，或在 Hub 前配置 HTTPS；不要把无认证的 HTTP Hub 直接暴露到公网。
3. 在 Hub 仪表盘中为每个真实订阅账号创建一条独立记录，例如“ChatGPT 主号”“ChatGPT 备用号”“Claude 工作号”。不同账号不要复用同一个 `accountId`。
4. 每台设备连接同一 Hub URL 和密钥，并设置唯一的 `deviceId`，例如 `office-pc`、`laptop`、`mac-mini`。
5. 在任意 Token Monitor 客户端打开“账号占用”视图，即可看到账号、活跃任务数、设备和红黄绿灰建议灯。

当前原型支持应用内托管 Hub 和 Node Hub；Cloudflare Worker 后端尚未实现短期占用记录的持久化与过期清理，建议作为后续独立 PR 补充。

## 各类客户端如何上报

### Claude Code、Codex 等 CLI

用 Token Monitor 包装原命令。任务启动时建立记录，运行中自动心跳，退出时自动释放：

```powershell
token-monitor-occupancy run --account "Claude 工作号" --project "商城" -- claude
token-monitor-occupancy run --account "ChatGPT 主号" --project "API" -- codex
```

包装器不读取提示词、回答或源代码，也不会因为红灯阻止命令启动。

### ChatGPT 网页

在每台电脑、每个浏览器 Profile 中加载 `browser-extension/`，配置相同 Hub URL、密钥、唯一设备 ID，以及该 Profile 所登录账号对应的 `accountId`。扩展只根据页面上可见的“正在生成/停止生成”控件上报状态，不读取或上传对话正文、Cookie 或 OpenAI 凭证。

建议一个浏览器 Profile 固定一个 ChatGPT 账号。若在同一 Profile 内切换账号，扩展无法从服务商凭证中安全识别新账号，必须同步修改映射。

### Claude 网页及没有适配器的桌面应用

使用仪表盘的手动“开始/结束”，或 CLI 的 `start`、`heartbeat`、`stop`。Claude 网页暂不自动采集，以避免未经授权的网页自动化访问。后续只有在服务商提供正式、允许的事件接口时再增加自动适配器。

## 指示灯含义

- 绿灯：当前没有收到活跃任务上报。
- 黄灯：至少有一个已上报任务，账号可能更忙。
- 红灯：活跃任务数达到你设置的建议阈值，建议人工选择其他账号或工具，但系统不会中断或禁止使用。
- 灰灯：监控已禁用、Hub 断开，或缺少足够的新鲜数据。

这些灯只反映已观测任务，不是服务商公布的并发上限，也不能保证实际延迟。网络、模型负载、上下文长度和服务商限流仍会影响“卡不卡”。

## 隐私与账号规则

Hub 只需要 Token Monitor 的共享密钥，不需要任何 AI 服务商密码、Cookie、OAuth Token 或 API Key。功能适用于你本人跨设备使用的账号，或组织正式分配给你的账号；不要把个人订阅账号共享给多人，也不要用多账号轮换规避服务商限制。
