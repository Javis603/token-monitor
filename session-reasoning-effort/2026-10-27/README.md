# Session reasoning effort

These screenshots render the production row builders in isolated Electron fixtures using synthetic sessions. They are layout evidence, not screenshots of real user conversations or native Notch pointer interaction.

- `overview.png`: Home, Sessions and Edge Dock; recent, idle, archived, unknown and grouped sessions.
- `notch.png`: Notch Home and Sessions; running, waiting, idle and archived sessions.

Effort uses plain text beside the model, remains visible after context/cache expiry, and has no tooltip. Model breakdown and context/cache tooltips remain available.

Claude fixtures additionally exercise the same production Home, Sessions, Edge Dock and Notch builders with recorded effort values, grouped main/child ownership, expired context and archived sessions. `claude-overview.png` and `claude-notch.png` use synthetic records and are rendering evidence, not native pointer/hover acceptance. Claude transcript extraction was separately checked against 20 real local main transcripts; no private transcript data is included here.
