# Token Monitor for iOS

A native, read-only companion for people who use multiple AI coding tools and want to check their measured usage, cost, quota headroom and session summaries from an authenticated Token Monitor Hub. The app does not collect local usage, request provider credentials, or fetch session transcripts.

The established desktop app and the user's supplied quota screenshot are the visual authority. Preserve its paired Session/Weekly readings, provider brand colors on meters, monochrome provider icons and account grouping when adapting to the phone. The original iOS Overview reference establishes one glass summary followed by continuous sections. Overview should make the current period's usage and quota headroom easy to scan. Insights supports reading historical trends and breakdowns. Native iOS navigation and accessibility take precedence over copying desktop dimensions.

Live Activities should display useful readings without repeating the Token Monitor wordmark. Use the ActivityKit host's transparent system material, with the default host treatment for Reduce Transparency; retain explicit stale/unknown states and the existing content customization. The user supplied T3 Code's transparent Lock Screen Live Activity as the material reference.

Debug demonstrations and Settings previews use illustrative data. Missing readings remain distinct from measured zero. Widgets read an App Group snapshot; update timing is controlled by iOS. Remote Activity updates require Hub APNs configuration and registration, and a local simulator demonstration does not prove remote APNs delivery.
