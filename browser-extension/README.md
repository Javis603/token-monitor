# Token Monitor 账号占用浏览器扩展

这是一个无需构建的 Chrome / Edge Manifest V3 扩展。它只在 `chatgpt.com` 和旧版 `chat.openai.com` 中检测可见、可用的“停止生成”按钮，并把“当前标签页可能正在生成”的状态报告为 Hub 短期任务记录。

Claude 网页自动检测默认不提供：Anthropic 个人条款对未经许可的自动化网页访问和采集限制较严格。Claude 网页请使用仪表盘手动登记；Claude Code 可使用本项目的 CLI wrapper。此选择是保守的产品合规边界，不代表法律意见。

## 安装与授权

1. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
2. 开启“开发者模式”，选择“加载已解压的扩展程序”。
3. 选择本目录 `browser-extension/`。
4. 打开扩展选项，填写 Hub URL、必填的共享密钥、设备 ID/名称，以及 ChatGPT 网站对应的 Hub `accountId`。
5. 保存时，浏览器只会请求访问该 Hub 地址的权限。扩展不会默认获得所有网站的访问权。

Hub URL 示例为 `http://192.168.1.10:17321`；它与 Token Monitor 多设备用量同步共用同一个 Hub。非本机连接会发送 bearer 密钥和任务元数据，必须使用 HTTPS 或可信的加密内网 VPN。

## 状态与手动覆盖

网页右下角状态点表示本标签页：绿色为空闲，红色为观察到正在生成，灰色为配置或连接错误。点击状态点可选择“占用”“释放”或恢复“自动”。这些操作只更新本地占用记录，不会提交、停止、重试或切换 ChatGPT 请求。

后台按“标签页 + 服务商”维护短期记录。页面每 15 秒报告一次；关闭标签页、开始导航或生成结束时释放。无法主动释放的旧记录会在 Hub 的 45 秒 TTL 后自动移除。

## 隐私与限制

扩展只向你配置的 Hub 发送：账号 ID、设备 ID/名称、服务商、固定任务标签、检测来源与可信度。它不会上传提示词、回答、网页正文、Cookie、OpenAI 凭证或浏览历史。

配置保存在 `chrome.storage.local`，不使用同步存储。Hub 共享密钥通过 `Authorization: Bearer …` 发送；任务的 `fenceToken` 只保存在 `chrome.storage.session`，不同步，也不持久化到磁盘。

DOM 检测只是推测信号。服务商修改页面结构、账号在同一浏览器会话内切换，或任务在后台继续运行时，都可能漏报或归属错误。建议每个浏览器 Profile 固定绑定一个 ChatGPT 账号，切换账号后重新确认映射。红黄绿灯仅供人工参考，绝不是服务商公布的并发上限或实际卡顿证明。
