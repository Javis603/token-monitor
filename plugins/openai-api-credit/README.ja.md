# OpenAI API Credits

Token Monitor の標準クォータ画面に、実際の OpenAI Platform API クレジット残高を表示します。

![クォータ画面の OpenAI API クレジット残高](assets/limits.png)

表示例です。残高と有効期限はアカウントによって異なります。

## 機能

- 標準プロバイダーと並べ替えられる **OpenAI** 項目。Codex のアイコンと配色、ユーザーの色設定を使用します。
- プログレスバーと残高、または残高のみの表示。
- 有効期限が異なる複数の利用可能なクレジットの残高と UTC 有効期限。
- 手動で入力し、App が検証・管理するログイン認証情報。
- 英語、繁体字中国語、簡体字中国語、日本語、韓国語、ブラジルポルトガル語の UI・README・変更履歴。

## 対応環境とインストール

**Token Monitor 0.88.0 以降**が必要です。

「**設定 → プラグイン**」で `.tmplugin` ファイルまたは完全なソースフォルダーをインポートし、内容を確認して有効にします。「**AI ツールのクォータ**」で **OpenAI** を選択して展開してください。インストールだけではアカウントは設定されません。

## 設定

1. OpenAI の設定にある請求ページ URL を普段のブラウザーにコピーし、ログインして組織を選択します。
2. DevTools（**F12** または **Cmd+Opt+I**）→ **Network** を開き、再読み込みして `credit_grants` を選択します。
3. **Headers → Request Headers** の `Authorization` を **Platform session token** に、`OpenAI-Organization` を **Organization ID** にコピーします。`Bearer` 接頭辞も入力できます。通常の API key、Cookie ヘッダー、ChatGPT/Codex のトークンは使用しないでください。
4. 認証情報を保存します。検証に成功すると編集欄が閉じます。「**クォータ**」に戻って残高を確認してください。

保存済みの値は認証情報の変更から置き換えられます。秘密の値が入力欄に再表示されることはありません。セッションが切れたら再取得してください。チャットやスクリーンショットで認証情報を共有しないでください。

## 表示と更新

残高は OpenAI から直接取得します。バーの総額には、現在利用可能で残高があるクレジットのみを含めます。期限切れや使い切ったクレジットは除外されるため、総額はその状態によって変わります。割合、バーの長さ、表示金額は App の使用済み／残量の設定に従います。使用済み金額は現在のクレジット枠を基準に計算します。

総額を確認できない場合は残高のみを表示します。バーの下には、利用可能なクレジットの最も早い既知の有効期限を表示します。有効期限が異なる利用可能なクレジットが2〜12件ある場合、ツールチップに各残高と有効期限を表示します。12件を超える明細は省略します。

更新は App のクォータ更新間隔、自動調整設定、画面の表示状態に従います。表示オプションは変更するとすぐに保存されます。認証情報の保存時には別途検証します。

## データとアクセス

App はユーザーデータディレクトリ内の `plugin-credentials/openai-api-credit/credits.json` に、非公開のアクセス権を持つ暗号化されていないファイルとして認証情報を保存します。プラグインコードや通常の設定とは別です。バックエンドは App のプロキシ対応通信を通じて `https://api.openai.com/v1/dashboard/billing/credit_grants` に送信します。この非公開仕様のエンドポイントや認証情報は変更・失効する場合があります。 Windows ではフォルダーから継承したアクセス権が適用され、App は所有者専用の ACL を設定しません。

プラグインは入力されたログイン認証情報を使用し、他の App のログインファイルの読み取りや分析データの送信は行いません。プラグインは信頼されたローカルコードとして動作し、OS ユーザーのファイルにアクセスできます。

## アップデート

「**設定 → プラグイン**」で新しいパッケージをインポートして更新内容を確認します。自動インストールは行いません。[変更履歴](CHANGELOG.ja.md)を参照してください。

リポジトリのルートからビルドする場合は、まだ存在しない出力先を指定します。

```sh
node scripts/build-plugin-package.js plugins/openai-api-credit ./openai-api-credit-0.1.0.tmplugin
```
