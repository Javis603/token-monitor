# OpenAI API Credits

Token Monitor의 기본 할당량 화면에 실제 OpenAI Platform API 크레딧 잔액을 표시합니다.

![할당량 화면의 OpenAI API 크레딧 잔액](assets/limits.png)

인터페이스 예시입니다. 잔액과 만료 시간은 계정에 따라 다릅니다.

## 기능

- 기본 제공자와 함께 정렬할 수 있는 **OpenAI** 항목. Codex 아이콘, 색상과 사용자 색상 설정을 사용합니다.
- 진행률 표시줄과 잔액 또는 잔액만 표시.
- 만료 시간이 다른 여러 사용 가능 크레딧의 잔액과 UTC 만료 시간.
- 직접 입력하고 App이 검증 및 관리하는 로그인 자격 증명.
- 영어, 번체 및 간체 중국어, 일본어, 한국어, 브라질 포르투갈어 UI, README와 변경 기록.

API 크레딧을 표시하며, ChatGPT 메시지 한도나 Costs 기반 추정 잔액이 아닙니다.

## 호환성 및 설치

기본 할당량 플러그인, 자격 증명 검증 및 기본 모양을 지원하는 Token Monitor(`tmApi: 1`)를 사용하세요. 할당량 모듈이 표시되지 않으면 App을 업데이트하세요.

**설정 → 플러그인**에서 `.tmplugin` 파일 또는 전체 소스 폴더를 가져오고 검토한 후 활성화하세요. **AI 도구 할당량**에서 **OpenAI**를 선택하고 펼치세요. 설치만으로 계정이 설정되지는 않습니다.

## 설정

1. OpenAI 설정의 청구 페이지 URL을 평소 쓰는 브라우저에 복사하고 로그인한 후 조직을 선택하세요.
2. DevTools(**F12** 또는 **Cmd+Opt+I**) → **Network**를 열고 새로고침한 후 `credit_grants`를 선택하세요.
3. **Headers → Request Headers**의 `Authorization`을 **Platform session token**에, `OpenAI-Organization`을 **Organization ID**에 복사하세요. `Bearer` 접두사를 포함해도 됩니다. 일반 API key, Cookie 헤더 또는 ChatGPT/Codex 토큰은 사용하지 마세요.
4. 자격 증명을 저장하세요. App이 검증하며 성공하면 편집기가 접힙니다. **할당량**으로 돌아가 잔액을 확인하세요.

자격 증명 변경으로 저장된 값을 바꿀 수 있습니다. 저장된 비밀 값은 입력란에 다시 표시되지 않습니다. 세션이 만료되면 새로 가져오세요. 채팅이나 스크린샷으로 자격 증명을 공유하지 마세요. 내장 로그인 브라우저를 사용하지 않습니다.

## 표시 및 새로고침

잔액은 서비스에서 직접 가져옵니다. 표시줄의 분모는 현재 사용 가능하며 잔액이 남은 크레딧의 지급액 합계입니다. 사용 가능한 $100과 비활성 $0/$24가 있으면 **$100 / $100**으로 표시합니다. 월간 또는 누적 지출이 아닌 현재 사용 가능 금액이며, 크레딧 만료나 소진에 따라 분모가 바뀝니다.

지급 내역으로 잔액을 정확히 설명할 수 없으면 잔액만 표시합니다. 0은 그대로 0입니다. 표시줄 아래에는 사용 가능한 크레딧 중 가장 빠른 만료 시간을 표시합니다. 만료 시간이 다른 여러 사용 가능 크레딧이 있을 때만 툴팁에 각 잔액을 표시합니다. 과거 총액을 반복하거나 만료 금액을 지출로 표시하지 않습니다.

새로고침은 App의 할당량 간격, 적응형 설정 및 화면 표시 상태를 따릅니다. 자격 증명 저장 시 별도로 검증합니다. 플러그인 자체 폴링 타이머는 없습니다. 설정에서 잔액만 표시하도록 선택할 수도 있습니다.

## 데이터 및 접근

App은 사용자 데이터 디렉터리의 `plugin-credentials/openai-api-credit/credits.json`에 개인 접근 권한을 가진 암호화되지 않은 파일로 자격 증명을 저장합니다. 플러그인 코드 및 일반 설정과 분리됩니다. 백엔드는 App의 프록시 지원 전송을 통해 `https://api.openai.com/v1/dashboard/billing/credit_grants`로 전송합니다. 문서화되지 않은 엔드포인트와 로그인 자격 증명은 변경되거나 만료될 수 있습니다.

인터페이스에는 정규화된 할당량 데이터만 전달됩니다. 다른 App의 로그인 파일을 읽거나 로그인 창을 열거나 분석 데이터를 전송하지 않습니다. 플러그인은 신뢰된 로컬 코드이며 OS 사용자 파일에서 격리되지 않습니다. 현재 기본 할당량 및 설정 화면과 통합됩니다.

## 업데이트

**설정 → 플러그인**에서 새 패키지를 가져오고 업데이트를 검토하세요. 자동으로 설치되지 않습니다. [변경 기록](CHANGELOG.ko.md)을 확인하세요.

저장소 루트에서 빌드하려면 아직 존재하지 않는 출력 경로를 지정하세요.

```sh
node scripts/build-plugin-package.js plugins/openai-api-credit /tmp/openai-api-credit-0.1.0.tmplugin
```
