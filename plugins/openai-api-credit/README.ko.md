# OpenAI API Credits

Token Monitor의 기본 할당량 화면에 실제 OpenAI Platform API 크레딧 잔액을 표시합니다.

![할당량 화면의 OpenAI API 크레딧 잔액](assets/limits.png)

인터페이스 예시입니다. 잔액과 만료 시간은 계정에 따라 다릅니다.

## 기능

- 기본 제공자와 함께 정렬할 수 있는 **OpenAI** 항목. Codex 아이콘, 색상과 사용자 색상 설정을 사용합니다.
- 진행률 표시줄과 잔액 또는 잔액만 표시.
- 만료 시간이 다른 여러 사용 가능 크레딧의 잔액과 UTC 만료 시간.
- 직접 입력하고 App이 검증 및 관리하는 로그인 자격 증명.
- 영어, 번체 및 간체 중국어, 일본어, 한국어, 브라질 포르투갈어 UI, README와 변경 기록.

## 호환성 및 설치

**Token Monitor 0.88.0 이상**이 필요합니다.

**설정 → 플러그인 → 탐색**에서 **Token Monitor** 공식 그룹의 **OpenAI API Credits**를 선택하고 검토한 후 설치하세요. **설정 → 플러그인**에서 `.tmplugin` 파일이나 전체 소스 폴더를 가져올 수도 있습니다. **AI 도구 할당량**에서 **OpenAI**를 선택하고 펼쳐 계정 자격 증명을 설정하세요.

## 설정

1. OpenAI 설정의 청구 페이지 URL을 평소 쓰는 브라우저에 복사하고 로그인한 후 조직을 선택하세요.
2. DevTools(**F12** 또는 **Cmd+Opt+I**) → **Network**를 열고 새로고침한 후 `credit_grants`를 선택하세요.
3. **Headers → Request Headers**의 `Authorization`을 **Platform session token**에, `OpenAI-Organization`을 **Organization ID**에 복사하세요. `Bearer` 접두사를 포함해도 됩니다. 일반 API key, Cookie 헤더 또는 ChatGPT/Codex 토큰은 사용하지 마세요.
4. 자격 증명을 저장하세요. App이 검증하며 성공하면 편집기가 접힙니다. **할당량**으로 돌아가 잔액을 확인하세요.

자격 증명 변경으로 저장된 값을 바꿀 수 있습니다. 저장된 비밀 값은 입력란에 다시 표시되지 않습니다. 세션이 만료되면 새로 가져오세요. 채팅이나 스크린샷으로 자격 증명을 공유하지 마세요.

## 표시 및 새로고침

잔액은 OpenAI에서 직접 가져옵니다. 표시줄 총액에는 현재 사용 가능하며 잔액이 남은 크레딧만 포함됩니다. 만료되거나 소진된 크레딧은 제외되므로 총액은 크레딧 상태에 따라 바뀝니다. 백분율, 표시줄 채움 및 표시 금액은 App의 사용량/잔여량 설정을 함께 따릅니다. 사용 금액은 현재 크레딧 한도를 기준으로 계산합니다.

총액을 확인할 수 없으면 잔액만 표시합니다. 표시줄 아래에는 사용 가능한 크레딧 중 가장 빠른 만료 시간을 표시합니다. 만료 시간이 다른 사용 가능 크레딧이 2~12개이면 툴팁에 각 잔액과 만료 시간을 표시합니다. 12개를 초과하면 상세 내역을 생략합니다.

새로고침은 App의 할당량 간격, 적응형 설정 및 화면 표시 상태를 따릅니다. 표시 옵션을 변경하면 즉시 저장됩니다. 자격 증명 저장 시 별도로 검증합니다.

## 데이터 및 접근

App은 사용자 데이터 디렉터리의 `plugin-credentials/openai-api-credit/credits.json`에 개인 접근 권한을 가진 암호화되지 않은 파일로 자격 증명을 저장합니다. 플러그인 코드 및 일반 설정과 분리됩니다. 백엔드는 App의 프록시 지원 전송을 통해 `https://api.openai.com/v1/dashboard/billing/credit_grants`로 전송합니다. 문서화되지 않은 엔드포인트와 로그인 자격 증명은 변경되거나 만료될 수 있습니다. Windows에서는 폴더에서 상속된 접근 권한을 따르며, App이 소유자 전용 ACL을 설정하지 않습니다.

플러그인은 직접 입력한 로그인 자격 증명을 사용하며 다른 App의 로그인 파일을 읽거나 분석 데이터를 전송하지 않습니다. 플러그인은 신뢰된 로컬 코드로 실행되며 OS 사용자 파일에 접근할 수 있습니다.

## 업데이트

**설정 → 플러그인**에서 새 패키지를 가져오고 업데이트를 검토하세요. 자동으로 설치되지 않습니다. [변경 기록](CHANGELOG.ko.md)을 확인하세요.

저장소 루트에서 빌드하려면 아직 존재하지 않는 출력 경로를 지정하세요.

```sh
node scripts/build-plugin-package.js plugins/openai-api-credit ./openai-api-credit-0.1.0.tmplugin
```
