# 配額提醒

當帳戶的工作階段配額不足、恢復或回滿時，透過桌面通知提醒你。

## 功能

- 僅在設定中顯示，開關變更立即儲存。
- 自訂提醒門檻；同一供應商與帳戶在配額恢復前只提醒一次。
- 桌面通知提供手動測試按鈕。
- 介面與 README 支援英文、簡體中文、繁體中文、韓文、日文及巴西葡萄牙文。

## 相容性

請使用 0.81.0 或以上、支援官方插件目錄的 Token Monitor。插件使用實驗性 `tmApi: 1` 介面。

插件使用已有配額讀數，不額外請求供應商。缺失或過期資料不會視為零。不提供主頁卡片、獨立頁面或全視窗閃動效果。

## 安裝

開啟**設定 → 插件 → 探索**，在 Token Monitor 官方分組選擇**配額提醒**，然後選擇**安裝並啟用**。選擇**僅安裝**可保持停用。請確認首次背景執行建議；插件總開關及安全模式仍然生效。

無需新增目錄 URL。也可以透過設定 → 插件匯入 `quota-alerts-0.1.0.tmplugin` 或完整原始碼資料夾。本機匯入顯示本機來源；官方身份來自 App 指定的官方目錄。

## 使用

1. 開啟插件設定，啟用**配額不足提醒**，並設定剩餘配額門檻，例如 10%。
2. 可按需要開啟**配額恢復／回滿提醒**。新讀數由低於門檻升回門檻或以上時發送恢復提醒；由未滿升至真實 100% 時發送回滿提醒。同一次回滿只發送一則通知，不會再重複發送恢復提醒。
3. 按下**測試桌面通知**檢查發送情況。會發送一則真實、帶有測試標示的通知，不會使用配額讀數或更改提醒去重紀錄。 即使兩個自動提醒開關都關閉，亦可測試通知。
4. 在插件管理中允許背景執行，才能在關閉設定頁後繼續接收提醒。App 會在首次設定時提出建議，你可以拒絕或稍後修改。Token Monitor 必須保持運行。

兩類提醒預設均關閉，可以獨立使用。首次讀數、來源變更及後端重新啟動會安靜地建立恢復基準，不會通知已滿額的帳戶；持續 100% 也不會重複提醒。單憑重置倒數結束不會視為恢復。

開關變更立即儲存。門檻在離開輸入欄位或按 Enter 時儲存；儲存失敗會還原已確認的值並顯示提示。

持續低配額不會重複提醒，恢復後才會重新觸發。App 重啟或來源身分改變可能開始新一輪提醒。發送失敗不會自動重試。

工作階段配額視窗新增或消失時，會先記錄新配額，不會立即宣告恢復或回滿。

通知範例：

```text
Codex 配額不足
Session: 剩餘 7%
```

```text
Codex 配額已回滿
Session: 剩餘 100%
```

## 資料與存取權限

插件是以本機使用者權限執行的受信任程式碼。此插件讀取已收集的配額資料及 App 語言設定，不讀取供應商憑證，也不主動查詢供應商。偏好與提醒紀錄儲存在 App 管理的插件資料目錄中。

桌面提醒使用宿主的通知操作。此插件不直接發送網絡請求。

## 更新

官方插件獨立於 App 發布更新。重新整理目錄後，選擇「更新」以檢視及批准相容版本；不會自動安裝。啟用狀態、偏好設定及已確認的背景執行選擇仍由使用者控制。探索及下載需要網際網路連線。回復版本只還原程式碼，不會撤回已發送的通知。
