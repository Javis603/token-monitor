# 配额提醒

当账户的会话配额不足、恢复或回满时，通过桌面通知提醒你。

## 功能

- 仅在设置中显示，开关更改立即保存。
- 自定义提醒阈值；同一供应商和账户在配额恢复前只提醒一次。
- 桌面通知提供手动测试按钮。
- 界面和 README 支持英文、简体中文、繁体中文、韩文、日文和巴西葡萄牙文。

## 兼容性

请使用 0.82.0 或以上、支持官方插件目录的 Token Monitor。插件使用实验性 `tmApi: 1` 接口。

插件使用已有配额读数，不额外请求供应商。缺失或过期数据不会视为零。不提供主页卡片、独立页面或整个窗口闪动效果。

## 安装

打开**设置 → 插件 → 探索**，在 Token Monitor 官方分组选择**配额提醒**，然后选择**安装并启用**。选择**仅安装**可保持停用。请确认首次后台运行建议；插件总开关及安全模式仍然生效。

无需添加目录 URL。也可以通过设置 → 插件导入 `quota-alerts-0.1.0.tmplugin` 或完整源码文件夹。本地导入显示本地来源；官方身份来自 App 指定的官方目录。

## 使用

1. 打开插件设置，启用**配额不足提醒**，并设置剩余配额阈值，例如 10%。
2. 可按需开启**配额恢复／回满提醒**。新读数从低于阈值回到阈值或以上时发送恢复提醒；从未满升至真实 100% 时发送回满提醒。同一次回满只发送一则通知，不再重复发送恢复提醒。
3. 点击**测试桌面通知**检查发送情况。会发送一条真实、带有测试标识的通知，不会使用配额读数或更改提醒去重记录。 即使两个自动提醒开关都关闭，也可以测试通知。
4. 在插件管理中允许后台运行，才能在关闭设置页后继续接收提醒。App 会在首次设置时提出建议，你可以拒绝或稍后修改。Token Monitor 必须保持运行。

两类提醒默认均关闭，可以独立使用。首次读数、来源更改及后端重新启动会安静地建立恢复基准，不会通知已经满额的账户；持续 100% 也不会重复提醒。仅凭重置倒计时结束不会视为恢复。

开关更改立即保存。阈值在离开输入框或按 Enter 时保存；保存失败会恢复已确认的值并显示提示。

持续低配额不会重复提醒，恢复后才会重新触发。App 重启或来源身份改变可能开始新一轮提醒。发送失败不会自动重试。

会话配额窗口新增或消失时，会先记录新配额，不会立即宣告恢复或回满。

通知示例：

```text
Codex 配额不足
Session: 剩余 7%
```

```text
Codex 配额已回满
Session: 剩余 100%
```

## 数据和访问权限

插件是以本地用户权限运行的受信任代码。此插件读取已收集的配额数据及 App 语言设置，不读取供应商凭据，也不主动查询供应商。偏好和提醒记录保存在 App 管理的插件数据目录中。

桌面提醒使用宿主的通知操作。此插件不直接发送网络请求。

## 更新

官方插件独立于 App 发布更新。刷新目录后，选择“更新”以查看并批准兼容版本；不会自动安装。启用状态、偏好设置及已确认的后台运行选择仍由用户控制。探索及下载需要互联网连接。回退版本仅还原代码，不会撤回已发送的通知。
