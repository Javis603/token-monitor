# 할당량 알림

계정의 세션 할당량이 부족하거나 회복되거나 100%로 돌아오면 데스크톱 알림을 받습니다.

## 기능

- 설정 화면에서만 표시되며 스위치 변경 사항을 즉시 저장합니다.
- 기준 비율을 지정할 수 있으며, 할당량이 회복될 때까지 공급자와 계정별로 한 번만 알립니다.
- 데스크톱 알림을 수동으로 테스트할 수 있습니다.
- 인터페이스와 README는 영어, 중국어 간체·번체, 한국어, 일본어, 브라질 포르투갈어를 지원합니다.

## 호환성

선택적 공식 카탈로그에 할당량 알림이 포함된 Token Monitor App 버전을 사용하세요. 플러그인은 실험적 `tmApi: 1` 인터페이스를 사용합니다.

기존 할당량 데이터를 사용하며 공급자에 추가 요청을 보내지 않습니다. 누락되거나 오래된 데이터를 0으로 처리하지 않습니다. 홈 카드, 독립 페이지 또는 전체 창 깜박임 효과는 제공하지 않습니다.

## 설치

이 선택적 공식 플러그인이 포함된 App에서 **설정 → 플러그인 → 탐색**을 열고 Token Monitor 공식 그룹의 **할당량 알림**을 선택한 뒤 **설치 및 활성화**를 선택하세요. **설치만** 선택하면 비활성 상태로 유지됩니다. 최초 설정의 백그라운드 실행 제안을 확인하세요. 플러그인 전체 스위치와 안전 모드는 계속 적용됩니다.

카탈로그 URL을 추가할 필요는 없습니다. 설정 → 플러그인에서 `quota-alerts-0.1.0.tmplugin` 또는 전체 소스 폴더를 가져올 수도 있습니다. 로컬로 가져온 사본은 로컬 출처로 표시되며, 공식 표시는 App에 포함된 패키지에 적용됩니다.

## 사용

1. 플러그인 설정에서 **할당량 부족 알림**을 켜고 남은 할당량 기준을 지정하세요. 예: 10%.
2. 필요하면 **할당량 회복 / 100% 알림**을 켜세요. 새 값이 기준 미만에서 기준 이상으로 돌아오면 회복 알림을, 100% 미만에서 정확히 100%가 되면 완전 회복 알림을 보냅니다. 같은 완전 회복에 일반 회복 알림을 중복해서 보내지 않습니다.
3. **데스크톱 알림 테스트**를 눌러 전송을 확인하세요. 테스트임을 표시한 실제 알림을 보냅니다. 할당량 값을 사용하거나 중복 알림 방지 기록을 변경하지 않습니다. 자동 알림 스위치가 모두 꺼져 있어도 테스트할 수 있습니다.
4. 설정 페이지를 닫아도 알림을 받으려면 플러그인 관리에서 백그라운드 실행을 허용하세요. App이 최초 설정에서 제안하지만 거부하거나 나중에 변경할 수 있습니다. Token Monitor는 실행 중이어야 합니다.

두 알림은 기본적으로 꺼져 있으며 독립적으로 사용할 수 있습니다. 첫 값, 소스 변경 후, 백엔드 재시작 후에는 조용히 회복 기준을 설정합니다. 이미 100%이거나 계속 100%인 경우에는 알리지 않습니다. 초기화 카운트다운 종료만으로 회복을 판단하지 않습니다.

스위치 변경 사항은 즉시 저장됩니다. 기준값은 입력란에서 벗어나거나 Enter를 누르면 저장됩니다. 저장 실패 시 확인된 값으로 복원하고 안내를 표시합니다.

할당량이 낮은 상태가 지속되어도 회복 전에는 반복 알림을 보내지 않습니다. App 재시작이나 소스 식별 정보 변경 시 새 알림이 발생할 수 있습니다. 전송 실패는 자동으로 재시도하지 않습니다.

세션 할당량 창이 추가되거나 사라지면 새 상태를 기록하며 즉시 회복이나 100% 알림을 보내지 않습니다.

알림 예시:

```text
Codex 할당량 부족
Session: 7% 남음
```

```text
Codex 할당량 100%
Session: 100% 남음
```

## 데이터와 접근 권한

플러그인은 로컬 사용자 권한으로 실행되는 신뢰된 코드입니다. 이 플러그인은 수집된 할당량 데이터와 App 언어 설정을 읽으며, 공급자 인증 정보를 읽거나 공급자를 직접 조회하지 않습니다. 환경 설정과 알림 기록은 App이 관리하는 플러그인 데이터 디렉터리에 저장됩니다.

데스크톱 알림은 호스트의 알림 작업을 사용합니다. 이 플러그인은 네트워크 요청을 직접 보내지 않습니다.

## 업데이트

공식 패키지는 App과 함께 업데이트됩니다. 변경된 플러그인 코드를 실행하기 전에 검토하고 승인하세요. 활성화 상태, 환경 설정, 확인한 백그라운드 실행 선택은 사용자가 계속 제어합니다. 롤백은 코드만 복원하며 이미 보낸 알림을 취소하지 않습니다.
