                    Rates · USD / 1M tokens
                    
                  

                  

                    Pricing guide
                    

                      
Override a model's price (USD per 1M tokens) when its auto-detected price is wrong. Applies to all providers of that model.

                      
Unused rates can be left blank. Custom pricing applies only when the rates cover every used token type.

                      
For a free model, set both input and output to 0 and leave other prices blank or 0.

                      
Cache-write rates are only needed for providers that bill cache writes separately. If the 1-hour rate differs, enter it manually.
